This repository records my progress in creating and structuring web pages with HTML. It also serves as a portfolio of evidence for my coursework.

- Structure content using HTML elements.
- Use headings to organise information.
- Create paragraphs and format text.
- Understand void elements.
- View HTML pages in a web browser.

## How to View

1. Select **Code → Download ZIP**.
2. Extract the downloaded folder.
3. Open an HTML file in a web browser.
4. Open the same file in a code editor to review its source.

No installation or build process is required.
